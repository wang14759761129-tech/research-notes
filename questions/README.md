# Research questions

Add a question when it arises from training, a learning exercise, or a paper. Record:

- The observation or source that prompted it.
- Why the answer would matter.
- Definitions and measurements needed.
- The smallest feasible investigation.
- What the available evidence cannot establish.
- A next action, or a reason to defer it.

Keep speculative questions labelled as speculative. Link them to an actual paper note or project when one exists.
